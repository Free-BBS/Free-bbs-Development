# FreeBBS 发展端

FreeBBS 发展端是 FreeBBS 主站的独立子页面项目，用于承载持续扩展的功能，并与主站共享登录状态和基础用户信息。

## 项目定位

- 作为 FreeBBS 体系中的独立发展端，与主站保持清晰边界。
- 承载需要独立迭代的页面与功能。
- 复用主站登录状态和基础用户信息，保持一致的用户体验。
- 在方案明确后逐步补充技术架构、接口协议和部署流程。

## 当前状态

项目处于初始化阶段。当前仓库只建立项目定位和文档入口，不预设具体技术栈、认证协议或部署方式。
